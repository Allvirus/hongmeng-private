# 前端对接-注册订单角色接口更新

## 目的

本次需要前端调整以下三类列表页查询与展示：

- 注册明细
- 订单明细
- 角色明细

涉及接口：

- GET /api/player/info
- GET /api/player/info/manage
- GET /api/player/order
- GET /api/player/order/manage
- GET /api/player/role
- GET /api/player/role/manage

## 本次变更摘要

### 1. 注册明细新增查询参数

- 参数名：IfunId
- 类型：long
- 含义：Ifun 平台账号数字 ID
- 后端实际匹配字段：PlayerInfo.IfunAccountId

### 2. 订单明细新增查询参数

- 参数名：IfunId
- 类型：long
- 含义：Ifun 平台内部行 ID
- 后端实际匹配字段：PlayerOrder.IfunId

### 3. 角色明细新增查询参数

- 参数名：IfunId
- 类型：long
- 含义：Ifun 平台内部行 ID
- 后端实际匹配字段：PlayerRole.IfunId

### 4. 角色明细新增返回字段

- accountCreateDate：账号注册时间
- createIp：注册 IP
- deviceNo：设备 ID

说明：

- createDate 仍表示角色创建时间，不是账号注册时间。
- 角色明细新增字段由后端通过 UserAccount 关联注册信息后返回。

## 前端修改点

### 查询表单

注册明细页新增输入项：

- IfunId

订单明细页新增输入项：

- IfunId

角色明细页新增输入项：

- IfunId

### 列表展示

角色明细页新增列：

- 账号注册时间，对应 accountCreateDate
- 注册 IP，对应 createIp
- 设备 ID，对应 deviceNo

## 接口说明

## 一、注册明细

### 1. 个人注册明细

- 地址：GET /api/player/info

请求参数：

| 参数名      | 类型     | 必填 | 说明                    |
| :---------- | :------- | :--- | :---------------------- |
| startTime   | datetime | 否   | 起始时间                |
| endTime     | datetime | 否   | 终止时间                |
| userAccount | string   | 否   | 用户账号                |
| account     | string   | 否   | 推广员账号              |
| createIp    | string   | 否   | IP                      |
| deviceNo    | string   | 否   | 设备号                  |
| ifunId      | long     | 否   | Ifun 平台账号数字 ID    |
| page        | int      | 否   | 页码，默认 1            |
| pageSize    | int      | 否   | 页大小，默认 5，最大 20 |
| platform    | int      | 否   | 平台，0=Ifun，1=木勺    |

返回字段重点：

- 本次无新增返回字段

请求示例：

```http
GET /api/player/info?userAccount=ms645741322&ifunId=645741322&platform=0&page=1&pageSize=10
```

### 2. 管理注册明细

- 地址：GET /api/player/info/manage

请求参数：

在个人注册明细基础上，额外支持：

| 参数名   | 类型 | 必填 | 说明        |
| :------- | :--- | :--- | :---------- |
| userId   | int  | 否   | 查询用户 ID |
| resDepId | int  | 否   | 查询部门 ID |

请求示例：

```http
GET /api/player/info/manage?resDepId=12&ifunId=645741322&platform=0&page=1&pageSize=10
```

## 前端联调建议

- 查询参数名统一使用 ifunId 传递。
- 注册页 ifunId 传的是账号数字 ID。
- 订单页和角色页 ifunId 传的是平台内部行 ID。
- 角色页需要新增 3 个表格列：accountCreateDate、createIp、deviceNo。
- 角色页若已有 createDate 列，不要改字段绑定，它仍然表示角色创建时间。
