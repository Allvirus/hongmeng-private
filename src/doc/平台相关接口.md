## 1.获取游戏注册分页信息

|       名称 | 描述                 |
| ---------: | -------------------- |
| 所属控制器 | **PlayerController** |
|   请求方式 | **Get**              |
|   接口地址 | **/api/player/info** |
|       备注 |                      |

> **请求参数（URL）**

|       参数名 |   类型   | 必填 | 描述                       |
| -----------: | :------: | :--: | -------------------------- |
|    startTime | datetime |  否  | 起始时间                   |
|      endTime | datetime |  否  | 终止时间                   |
|  UserAccount |  string  |  否  | 用户账号                   |
|      Account |  string  |  否  | 推广员账号                 |
|     CreateIp |  string  |  否  | IP                         |
|     DeviceNo |  string  |  否  | 设备号                     |
|         Page |  string  |  否  | 页码默认为 1               |
|     PageSize |  string  |  否  | 页数大小默认为 5 最大为 20 |
| **Platform** | **int**  |  否  | **平台（0=Ifun，1=木勺）** |

> **返回值**

```json
{
  "list": [
    {
      "id": "a7b09937-1804-4ea6-a394-d646a79fc80b",
      "account": "mlh0808",
      "userAccount": "ms645741322",
      "userCode": "cda7cabddb",
      "createIp": "120.87.145.189",
      "createDate": "2020-09-27T08:40:15",
      "osType": "2",
      "deviceNo": "",
      "ajob": null,
      "ajobId": 0,
      "bjob": null,
      "bjobId": 0,
      "cjob": null,
      "cjobId": 0,
      "platform": 0
    }
  ],
  "count": 18,
  "code": 200,
  "data": null
}
```

}
