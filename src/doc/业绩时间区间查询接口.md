# 业绩时间区间查询接口

本文档仅说明新增的业绩时间区间查询接口：

- GET /api/achievement/range
- GET /api/achievement/range/manage

返回格式与现有周报、月报接口保持一致，均返回按天聚合的业绩列表和注册数。

---

## 1. 个人时间区间业绩

|       名称 | 描述                                       |
| ---------: | ------------------------------------------ |
| 所属控制器 | AchievementController                      |
|   请求方式 | Get                                        |
|   接口地址 | /api/achievement/range                     |
|       备注 | 查询当前登录用户在指定时间区间内的业绩数据 |

> 请求参数（URL Query）

|       参数名 |   类型   | 必填 | 描述                               |
| -----------: | :------: | :--: | ---------------------------------- |
|    startTime | datetime |  否  | 开始时间，按天统计                 |
|      endTime | datetime |  否  | 结束时间，按天统计                 |
| gamePlatform |  string  |  否  | 平台名称，当前服务未使用该字段过滤 |
|     gameName |  string  |  否  | 游戏名称                           |
|     areaName |  string  |  否  | 区服名称                           |

说明：

- 当未传 startTime 时，默认取当天。
- 当未传 endTime 时，默认取当天。
- 当 endTime 小于或等于 startTime 时，后端会自动按 startTime 当天处理，即统计 startTime 当天数据。
- 返回结果按天倒序排列。

> 返回值

```json
{
  "code": 200,
  "data": [
    {
      "timeKey": "2026-03-26T00:00:00",
      "dayKey": 26,
      "userRoleCount": 18,
      "userCount": 12,
      "rechargeCount": 9,
      "rechargeUserCount": 6,
      "sum": 1288.5
    }
  ],
  "registerCount": 23
}
```

字段说明：

|        字段名 |      类型      | 说明                          |
| ------------: | :------------: | ----------------------------- |
|          code |      int       | HTTP 语义状态码，正常返回 200 |
|          data | GroupDayData[] | 按天汇总的业绩数据            |
| registerCount |      int       | 时间区间内注册数              |

GroupDayData 字段说明：

|            字段名 |   类型   | 说明           |
| ----------------: | :------: | -------------- |
|           timeKey | datetime | 日期           |
|            dayKey |   int    | 日             |
|     userRoleCount |   int    | 创建角色数     |
|         userCount |   int    | 创建角色用户数 |
|     rechargeCount |   int    | 充值次数       |
| rechargeUserCount |   int    | 充值用户数     |
|               sum | decimal  | 充值金额汇总   |

## 2. 管理时间区间业绩

|       名称 | 描述                                             |
| ---------: | ------------------------------------------------ |
| 所属控制器 | AchievementController                            |
|   请求方式 | Get                                              |
|   接口地址 | /api/achievement/range/manage                    |
|       备注 | 查询指定用户或指定部门范围在时间区间内的业绩数据 |

> 请求参数（URL Query）

|       参数名 |   类型   | 必填 | 描述                               |
| -----------: | :------: | :--: | ---------------------------------- |
|    startTime | datetime |  否  | 开始时间，按天统计                 |
|      endTime | datetime |  否  | 结束时间，按天统计                 |
| gamePlatform |  string  |  否  | 平台名称，当前服务未使用该字段过滤 |
|     gameName |  string  |  否  | 游戏名称                           |
|     areaName |  string  |  否  | 区服名称                           |
|       userId |   int    |  否  | 指定查询用户 Id                    |
|     resDepId |   int    |  否  | 指定查询部门 Id                    |

说明：

- 当 userId 大于 0 时，优先按该用户查询，resDepId 不生效。
- 当 userId 小于等于 0 且 resDepId 大于 0 时，按该部门及其关联范围查询。
- 当 userId 小于等于 0 且 resDepId 等于 0 时，按当前登录用户可管理部门范围查询。
- 时间处理规则与个人接口一致。
- 返回结果按天倒序排列。

> 返回值

```json
{
  "code": 200,
  "data": [
    {
      "timeKey": "2026-03-25T00:00:00",
      "dayKey": 25,
      "userRoleCount": 35,
      "userCount": 28,
      "rechargeCount": 17,
      "rechargeUserCount": 11,
      "sum": 3566.0
    }
  ],
  "registerCount": 41
}
```

返回结构与 /api/achievement/range 完全一致。

## 3. 前端调用示例

### 3.1 查询个人时间区间业绩

```http
GET /api/achievement/range?startTime=2026-03-01&endTime=2026-03-26&gameName=传奇世界&areaName=S1
```

### 3.2 查询指定用户时间区间业绩

```http
GET /api/achievement/range/manage?startTime=2026-03-01&endTime=2026-03-26&userId=25
```

### 3.3 查询指定部门时间区间业绩

```http
GET /api/achievement/range/manage?startTime=2026-03-01&endTime=2026-03-26&resDepId=8
```
